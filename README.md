# 🚀 Trading Platform

> Профессиональная алгоритмическая торговая система

## 📦 Архитектура
- **Frontend**: Next.js, TypeScript, Tailwind
- **Backend**: Rust (Actix), PostgreSQL, Redis
- **ML**: Python pipeline (XAI, RL)
- **Infra**: Docker, pnpm monorepo

## 🛠 Быстрый старт
\\\ash
git clone https://github.com//trading-platform.git
cd trading-platform
cp .env.example .env
pnpm install
pnpm docker:up
pnpm dev
\\\

## 🔐 Конфигурация
Скопируйте \.env.example\ в \.env\ и заполните ключи API.
